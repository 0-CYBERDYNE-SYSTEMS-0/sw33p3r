TL;DR — The 60-Second Answer

Momentum firmware is Flipper Zero only. It cannot run on ESP32, HackRF, or any other device. Period.
QuestionAnswer
Cheapest standalone with sub-GHz + WiFi + BLE? LilyGo T-Embed CC1101 (~$30–45) running Bruce firmware. Has a display, battery, rotary encoder, and native CC1101.
What is "TLITMB"? A typo for LilyGo T-Embed. No device called "TLITMB" exists. (See full breakdown ↓)
Can the BFFB run standalone? No. The BFFB has no display, no battery, no input, no standalone firmware. It requires a Flipper Zero.
Most capable RF survey? HackRF One + PortaPack H4M with Mayhem firmware (~$180–220). Covers 1 MHz to 6 GHz — every band, one device.
Any device with CC1101 + nRF24 built in? Only the BFFB (Flipper add-on). No standalone ESP32 board ships with both. T-Embed CC1101 has CC1101 but no nRF24.

🔍 "TLITMB Go" — What Is It?

After thorough research across GitHub, Reddit, AliExpress, and LilyGo's own site: there is no device called "TLITMB." This does not exist as a product, project, or codename.

Best explanation: It's a typo for LilyGo T-Embed — specifically the T-Embed CC1101 variant. Someone typing quickly on a phone keyboard could easily mangle "T-L-I" into "TLITMB" via autocorrect, and "go" may refer to a firmware version or the Go programming language being used with it.

The LilyGo T-Embed CC1101 (~$30–45) is the most relevant device for this use case because it's the cheapest standalone handheld that ships with a CC1101 sub-GHz radio, WiFi/BLE via ESP32, a color display, a battery, and a rotary encoder for navigation. It runs Bruce firmware natively and is widely used in the wireless security community.

Momentum is Flipper Zero only. The Room Sweep FAP is a Flipper application written in C against Momentum's API (furi, gui, subghz, etc.). It cannot be ported to ESP32 without a complete rewrite. However, other firmware already does what Room Sweep does — sometimes more.

Key insight: Bruce firmware on a T-Embed CC1101 already does sub-GHz scanning, WiFi scanning, and BLE scanning in a standalone handheld for ~$30. It has TX/attack modes that Room Sweep deliberately avoids (per MISSION.md), but the passive survey capabilities are the same use case. If replacing the Flipper entirely is the goal, Bruce on T-Embed CC1101 is the closest off-the-shelf equivalent.

🎯 Recommendations by Goal

Keep Flipper, Add Radio

Flipper Zero + FlipMods Ultra V3

~$169 + $45 = ~$214

Stick with your existing Flipper. The Ultra V3 is a budget BFFB alternative with CC1101 + nRF24 + ESP32. Half the price of a BFFB, same radios. Room Sweep already targets the BFFB's ESP32 Marauder interface — adapting to the Ultra V3's UART is minimal work.

Cheapest Standalone

LilyGo T-Embed CC1101 + Bruce

~$30–45

A completely separate device from Flipper. Runs Bruce firmware with sub-GHz scanning, WiFi, BLE. No Flipper needed. No nRF24. This is the "TLITMB" device — a standalone RF survey tool for under $50.

Most Capable Survey

HackRF One + PortaPack H4M + Mayhem

~$180–220

1 MHz to 6 GHz true SDR. Spectrum analyzer, signal identification, full survey across all bands. This is what professionals use. No WiFi/BLE scanning natively — but nothing beats it for raw RF visibility. Complements a Flipper, doesn't replace it.

DIY Maximum

Breadboard: ESP32 + CC1101 + nRF24

~$7–37

The cheapest path to hardware parity with a Flipper+BFFB. All three radios, your choice of display. Most software work — you'd need to port or write firmware. Not plug-and-play.

🔮 The Bottom Line

The Flipper Zero ecosystem is not the only game in town for RF surveying. The ESP32 world has exploded with alternatives:

  • For $30: T-Embed CC1101 running Bruce does sub-GHz + WiFi + BLE in a handheld. It's the spiritual equivalent of what Room Sweep does.
  • For $45: FlipMods Ultra V3 adds CC1101 + nRF24 to your Flipper without the $146 BFFB price tag.
  • For ~$200: HackRF + PortaPack H4M is a true professional-grade SDR spectrum analyzer covering literally every band you'd ever survey.
  • For ~$12: A CYD ESP32 board runs Marauder for WiFi/BLE — add a $3 CC1101 module and you have sub-GHz too.
Room Sweep's detect-only mission is unique. All existing ESP32 firmware (Bruce, Marauder, GhostESP) includes attack modes (deauth, beacon spam, jamming) that Room Sweep deliberately avoids. If you want a passive-only survey tool on cheap hardware, you'd need to either strip attack modes from Bruce or write a new firmware. Room Sweep on Flipper + BFFB remains the only passive-only integrated solution — but the hardware is expensive and the BFFB is hard to obtain.
