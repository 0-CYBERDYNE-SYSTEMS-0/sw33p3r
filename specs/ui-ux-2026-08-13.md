## Verified constraint (blocks swipe design)

Momentum mntm-012 SDK header `applications/services/input/input.h` defines
`InputType` as `{Press, Release, Short, Long, Repeat, MAX}` only.
**No swipe gesture event types exist on this target.** All swipe-based
gesture plans are void; documented as Pitfall #18 in FLIPPER_PITFALLS.md.

Available input dimensions on this target:
- `Press` (debounced press, fires before Short/Long) — untapped.
- `Release` (fires after every press; distinguishes tap vs hold) — untapped.
- `Long` on Up/Down (currently collapsed into Browse) — untapped via a NEW
  phase-aware seam (existing safety table stays untouched).
- `Secondary` (long OK) on GPS tab — free slot.
- Repeat stays browse-only for safety; OK/Left/Right/Back repeat stay dead.
